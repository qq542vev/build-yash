# Build Yash

Build Yashは、Linux環境を前提として複数アーキテクチャ向けにビルドした[Yash](https://magicant.github.io/yash/)のパッケージを配布するプロジェクトです。Ubuntu 18.04の環境でスタティックな設定に基づきビルドを行っています。[Releasesページ](https://gitlab.com/qq542vev/build-yash/-/releases)から任意のバージョンのYashがダウンロード可能です。
